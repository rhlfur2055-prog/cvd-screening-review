# 논문 읽기 절차

1. **입력 확인**: PMID이면 `get_paper`(MCP) 또는 `uv run python -m src.agent.cli collect <PMID>`로 초록·오픈액세스 여부를 가져온다. 전문이 없으면 "초록 기반"이라고 명시한다.
2. **추출** — 아래 스키마를 빠짐없이 채운다. 원문에 없는 항목은 `미기재`로 쓴다(추측 금지).

```
제목 / 저널·연도 / PMID
연구 질문 (1문장)
설계·표본 (n, 집단, 검사 방법)
핵심 수치 (값, 단위, 신뢰구간, 조건) — 원문 표현 그대로
저자가 명시한 한계
전문 접근: 오픈액세스 여부, 초록만 읽었는지
```

3. **수치 게이트**: 핵심 수치는 `data/claims.json`에 항목으로 추가하고 `cli verify`로 초록 대조를 돌린다. `unverified-in-abstract`이면 결론에 쓰지 말고 "전문 확인 필요"로 표시한다.
4. **판단 기준(연구자 스타일)**
   - 조건이 붙은 수치(예: "8오류 기준 95.5%")는 조건까지 함께 옮긴다.
   - 저자가 검증하지 않은 주장은 저자 주장과 내 추론을 분리해 쓴다.
   - "상위 N%" 류 근거 없는 수치 훅을 만들지 않는다.
5. **출력**: 위 스키마 + "이 논문이 우리 논문(paper/main.md)의 어느 주장을 뒷받침/반박하는가" 한 줄.
