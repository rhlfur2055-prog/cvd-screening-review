# 실험 로그 정리 절차

1. **수집**: `results/`의 산출물과 실행 명령·시각·코드 버전(`git rev-parse --short HEAD`)을 한 항목으로 묶는다.
2. **표준 기록** (`results/EXPERIMENT_LOG.md`에 추가, 덮어쓰지 않는다)

```
## <날짜> <실험명>
명령: ...
입력·가정: (출처 있는 값 / 가정† 구분)
결과 요약: 표·수치 (실행에서 나온 값만)
상태: 성공 | 실패 | 부분
```

3. **실패 분석**: 원인을 (a) 입력/가정 문제, (b) 코드 버그, (c) 데이터 부족 중 하나로 분류하고 근거 출력을 인용한다. 원인 불명이면 "불명"이라 쓴다.
4. **다음 실험 제안**: 최대 3개. 각각 `가설 → 바꿀 변수 → 기대 결과 → 그 결과가 나오면 논문의 어떤 문장이 바뀌는가`.

## 품질 규칙 (위반 시 결과를 폐기하고 재실행)

- 표의 모든 수치는 스크립트 출력과 일치해야 한다. 손으로 고친 값 금지.
- 가정값은 반드시 †로 표시하고 결과 문장에 "가정 조건부"를 붙인다.
- 실패한 실험도 삭제하지 않고 로그에 남긴다.
- 실행하지 않은 결과를 "실험했다"고 쓰지 않는다.
